## Critical Bugs Fixed

### 1. tryRedoxBalancing Always Returns Null (Critical #1)
**Location**: `src/reactions.js:3588-3607`

**Problem**: Function called `detectRedoxChanges()` with only reactant data, no products. Since `detectRedoxChanges` requires both reactants and products to identify oxidation state changes, it always returned null.

**Fix**: Rewrote to directly analyze reactants and identify potential redox pairs by:
- Parsing all reactant formulas
- Determining oxidation states for each element
- Checking which elements can be oxidized/reduced based on known oxidation states
- Passing identified pairs to `tryBuildRedoxProducts()`

**Impact**: Redox reactions now properly detected and balanced.

---

### 2. Peroxide/Superoxide Detection Wrong (Critical #6)
**Location**: `src/data/oxidation-states.js:79-84`

**Problem**: Peroxide detection checked `parsed.get('Na') === 2` without checking O count, causing false positives:
- Na2O (normal oxide, O should be -2) matched and returned -0.5
- Na2O2 (peroxide, O should be -1) matched and returned -0.5
- KO2 (superoxide, O should be -0.5) didn't match at all

**Fix**: Rewrote peroxide/superoxide detection to check O:metal ratio:
```js
if (sym === 'O') {
  const oCount = parsed.get('O');
  // Peroxide: O count equals metal count (H2O2, Na2O2, K2O2)
  if (parsed.size === 2 && parsed.has('H') && parsed.get('H') === oCount && oCount >= 2) return -1;
  for (const alkali of ['Na', 'K', 'Rb', 'Cs']) {
    if (parsed.has(alkali)) {
      const metalCount = parsed.get(alkali);
      if (oCount === metalCount && oCount >= 2) return -1;  // peroxide
      if (oCount === 2 * metalCount && metalCount >= 1) return -0.5;  // superoxide
    }
  }
  return -2;  // normal oxide
}
```

**Impact**: Correct oxidation states for peroxides (-1), superoxides (-0.5), and normal oxides (-2).

### 3. Oxide Formula Wrong for Odd Charges (Critical #7)
**Location**: `src/reactions.js:3789, 3724`

**Problem**: Used `Math.ceil(targetState / 2)` for oxide formula, generating incorrect formulas:
- Al^3+ → AlO2 (wrong, should be Al2O3)
- Fe^3+ → FeO2 (wrong, should be Fe2O3)

**Fix**: Implemented criss-cross method using GCD:
```js
const g = gcd(Math.abs(targetState), 2);
const metalSub = 2 / g;
const oSub = Math.abs(targetState) / g;
const metalPart = metalSub === 1 ? sym : `${sym}${metalSub}`;
const oPart = oSub === 1 ? 'O' : `O${oSub}`;
```

**Examples**:
- Al^3+: gcd(3,2)=1 → Al₂O₃ ✓
- Mg^2+: gcd(2,2)=2 → MgO ✓
- Na^1+: gcd(1,2)=1 → Na₂O ✓

**Impact**: Correct oxide formulas for all charge states.

## Warnings Fixed

### Warning #9: Elimination Hardcodes Na Salt
**Location**: `src/reactions.js:2868`

**Problem**: `tryElimination` always generated Na(halide) salt regardless of base cation (NaOH vs KOH).

**Fix**: Extract cation from base formula:
```js
const baseCation = baseFormula.startsWith('K') ? 'K' : 'Na';
const saltFormula = `${baseCation}${halSym}`;
```

**Impact**: E1/E2 elimination now produces correct salt (KCl with KOH, NaCl with NaOH).

---

### Warning #10: Nitration Bond Index Out of Bounds
**Location**: `src/reactions.js:3044-3046`

**Problem**: Bond indices calculated incorrectly, creating self-loops and out-of-bounds references:
```js
productBonds.push([ringH, o1Idx, 2]);  // wrong: should bond to N, not ring C
productBonds.push([ringH, o2Idx, 1]);  // wrong: should bond to N
productBonds.push([o2Idx, productAtoms.length - 1 + 1, 1]);  // out of bounds
```

**Fix**: Correct nitro group structure (C-N with two N-O bonds):
```js
productBonds.push([ringH, hIdx, 1]);  // ring C to N
productBonds.push([hIdx, o1Idx, 2]);  // N to O (double bond)
productBonds.push([hIdx, o2Idx, 1]);  // N to O (single bond)
```

**Impact**: Aromatic nitration produces valid molecular structures.

### Warning #11: Dead Truthiness Check
**Location**: `src/reactions.js:3434-3436`

**Problem**: Checked if `generateSingleAtomTemplate` function exists (always true):
```js
if (!T[pf]) T[pf] = generateSingleAtomTemplate
  ? (generateSingleAtomTemplate(...) || { atoms: [], bonds: [] })
  : { atoms: [], bonds: [] };
```

**Fix**: Removed dead check:
```js
if (!T[pf]) T[pf] = generateSingleAtomTemplate(...) || { atoms: [], bonds: [] };
```

**Impact**: Cleaner code, no behavioral change.
